# Jana Meriden — Portfolio

Personal portfolio site for Jana Meriden, a Communications & Electronics Engineering student at Cairo University (class of 2027) focused on RF, mobile networks and satellite communications.

**Live site:** https://jmeriden.github.io/JanaMeridensPortofolio.github.io/

## What's on it
- **RF & Telecom:** NileSat satellite communications internship, Nokia × Orange mobile networks internship, graduation project (5G, 6G & Future Networks track), and 2G–5G professional training
- **Projects:** case studies for a SQL Server/.NET database system, a miniature OS in C, an alien-invasion simulation game in C++, and a flowchart simulator with a GUI

## Built with
HTML, CSS, JavaScript and Bootstrap 5, hosted on GitHub Pages.
